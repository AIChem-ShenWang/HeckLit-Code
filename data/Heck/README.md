# Data from the Reaxys repository

For getting data from Reaxys: 
1. Go to the “Qiuck search” tab on the Reaxys website (www.reaxys.com)
2. Input "Heck" as key word and search in the inquiry column
3. Select "Reaction" and click the "View Results" button
4. Select all related reactions and exported as "Tab-delimited text" in several batches
5. After deleting some irrelevant information and use Python to organize the dataframe, "Heck raw data.xlsx" is obtained
